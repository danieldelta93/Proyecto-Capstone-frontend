# Documentación del proyecto Vendix

Documentos del proyecto APT (Capstone). Cada uno está en formato Markdown (para leer en GitHub) y Word (`.docx`, para entregar).

| Documento | Contenido |
|---|---|
| `Documento_Inicio_Proyecto_Vendix` | Problema, objetivos, **alcance MVP**, **restricciones**, riesgos, equipo y cronograma |
| `Metodologia_Scrum_Vendix` | Metodología Scrum **justificada**, roles, eventos y artefactos |
| `Product_Vision_Vendix` | Visión del producto, usuarios y propuesta de valor |
| `Product_Backlog_Vendix` | 33 historias de usuario priorizadas con su estado |
| `Sprint_Backlog_Vendix` | Sprints 0 a 6: objetivos, tareas y estado |
| `Definition_of_Done_Vendix` | Definición de terminado y criterios de aceptación |
| `Retrospectivas_Vendix` | Retrospectiva de cada sprint |
| `Requisitos_No_Funcionales_Vendix` | Rendimiento, seguridad, usabilidad, etc., con metas medibles |
| `Diagramas_UML_Vendix` | Casos de uso, clases, secuencia, componentes, arquitectura y modelo entidad-relación |
| `Plan_Pruebas_Vendix` | Plan de pruebas, resultados, defectos y trazabilidad |
| `Manual_Tecnico_Vendix` | Instalación, configuración, ejecución, publicación y respaldos |
| `Innovacion_Vendix` | Qué aporta Vendix y en qué se diferencia |

Las imágenes de los diagramas están en `img/` junto con sus archivos fuente editables (`.mmd`).
Documentación técnica del backend (arquitectura, modelo de datos y API): carpeta `Codigo/docs/` del repositorio del backend.
